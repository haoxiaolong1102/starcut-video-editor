# Licensing and provenance boundaries

- StarCut's MIT license covers only the original files in this package.
- A tool being installed locally does not grant permission to redistribute it.
- Do not embed third-party binaries, source, models, fonts, footage, screenshots, SFX, music, Lottie files, or templates without a documented license and required notices.
- User-provided assets remain outside the Skill ZIP and need a permission/provenance record in each project.
- External dependencies retain their own licenses; the user's use case may change eligibility.
- OpenChatCut and video-talkcraft are external-only. Never copy their source or effect recipes into StarCut.
- Remotion is external and governed by its current source-available license; check organizational eligibility before production use.
- FFmpeg license depends on the actual build configuration. Do not redistribute an unknown binary.
- Face-landmarker and transcription model files are separate artifacts whose provenance must be checked independently from the Python package.
- Generated media must record provider, model/service, date, prompt/brief, and terms applicable at generation time.

See `LICENSE_AUDIT.md` and `THIRD_PARTY_NOTICES.md` for the audited release boundary.
