# SMART VISUAL ROUTER

Choose the visual after identifying the sentence's semantic job.

## Evidence priority

1. Real evidence or primary source.
2. Real screen recording of the claimed operation.
3. Real screenshot with restrained focus treatment.
4. Original infographic that accurately restructures known facts.
5. Original generated visual for an abstract or unavailable scene.
6. Pure decoration only when it supports pacing without displacing meaning.

Never replace available proof with prettier generated imagery.

## Routing table

| Semantic role | First choice | Useful alternative | Avoid |
|---|---|---|---|
| personal opinion/emotion | presenter | restrained environment B-roll | unnecessary diagrams |
| software action | real screencast + Screen Focus | verified screenshots | fake interface |
| person/company/product | authentic photo/logo/page | licensed B-roll | invented evidence |
| number/trend | data visual with source | concise number card | decorative counters |
| A/B distinction | comparison or match transition | split information card | unrelated collage |
| steps/process | progressive flow | numbered actions | dense static slide |
| causal/structural mechanism | relationship diagram | 2D layers; 3D only if spatial | random particles |
| story/emotional scenario | continuous picturebook or B-roll | presenter + inserts | unrelated one-off images |
| warning/constraint | presenter or evidence with restrained emphasis | short kinetic type | alarm-like flashing |
| recap/CTA | presenter + compact conclusion | branded end card | long promotional outro |

## Selection test

For each candidate ask:

1. Does it make this sentence easier to understand or trust?
2. Is it the most authentic available source?
3. Can a phone viewer read it without pausing?
4. Does it fit the same visual system and continuity?
5. Is a lower-complexity treatment equally clear?

If question 1 is no, use `talking_head` or `none`. If question 5 is yes, choose the lower level.

## Density and fatigue

- Avoid long stretches of only presenter plus ordinary captions, but do not force a visual change on every sentence.
- Change visual state at semantic boundaries, not on arbitrary beat counts.
- Treat silence removal, framing, and a clear face as valid direction—not “missing effects.”
- A visual insert should generally remain long enough to read and understand; do not flash evidence.
