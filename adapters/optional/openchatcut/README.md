# OpenChatCut optional adapter

OpenChatCut is not bundled. The audited local checkout declares `AGPL-3.0-or-later`; users install and operate it separately.

When configured, set `STARCUT_OPENCHATCUT_URL` to the user's local endpoint. The StarCut agent may then use the external editor only through its currently documented interface and must verify returned timeline/project state. Never copy OpenChatCut source, fonts, media, or generated project cache into this Skill.

Fallback: renderer-native timeline or StarCut edit manifest. Missing OpenChatCut never blocks planning or production.
