# Music adapter

Music is optional. A future Mureka, MiniMax, Atlas, Sonilo, or local-library implementation must return the contract in `references/audio-and-music.md` and an actual licensed file.

No key/file → `NO_MUSIC` → continue production.

The adapter must never:

- report success without an audio file
- generate random tones as a substitute
- hide usage cost or licensing status
- overwrite narration
- upload the project without explicit authorization
